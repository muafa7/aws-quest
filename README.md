# AWS Quest

A retro-style personal learning app for AWS certification preparation.

## Target certifications

- AWS Certified Cloud Practitioner (CLF-C02)
- AWS Certified Solutions Architect – Associate (SAA-C03)

## Core idea

AWS Quest combines short lessons, immediate retrieval practice, confidence tracking, adaptive question selection, spaced review, concept mastery, and mock exams in a retro developer-RPG interface.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Prisma ORM 7 (planned in the next milestone)
- SQLite
- Zod
- pnpm

## Development

```bash
corepack enable
pnpm install
pnpm dev
```
